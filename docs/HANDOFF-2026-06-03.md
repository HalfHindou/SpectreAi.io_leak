## Key architecture decisions (today)

1. **L4 inversion: Hetzner-primary, Codex-fallback.** Every user-facing route now hits Hetzner first; Codex is the residual. See `apps/research/api/_lib/spectre-data.js` for the 4-tier helper (KV → /v1/coins/markets → /v1/scanner/token → DexScreener).

2. **Chart tier chain:** Binance klines (majors) → Hetzner candles_1m (top-100) → GeckoTerminal (degen long-tail) → Codex (final residual). 99%+ of chart loads now free.

3. **CDN cache pattern:** any public read-only proxy gets `CDN-Cache-Control: public, s-maxage=N, stale-while-revalidate=2N` + `Vary: Accept-Encoding`. This bypasses Vercel's default "cookies disable edge cache" behavior. Don't apply to `/api/user/*`, `/api/swap/*`, anything user-specific.

4. **Auth-gate 401 protocol:** when fetchJSON gets 401 + `code: 'GATE_REQUIRED'`, force `window.location.reload()` so AuthGate re-prompts instead of silently failing. Currently only in TradingViewAdvanced.jsx — should be applied to any frontend hook that calls auth-gated APIs.
